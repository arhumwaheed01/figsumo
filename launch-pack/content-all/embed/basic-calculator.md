H1: Free Basic Calculator Widget
Sometimes visitors just need to add up a few numbers without leaving your page. This generator gives you a free calculator widget to embed on a blog, shop, classroom page or intranet with one line of code.
How to use the embed generator
1. Sample expression: type something like 12*(3+4) to check the result. The preview follows the usual order of operations.
2. Embed width (px): 280 to 960 (default 480).
3. Copy the embed code from the results:
<iframe src="https://figsumo.com/scientific-calculator" width="480" height="520" style="border:0;border-radius:8px" loading="lazy" title="Math calculator"></iframe>
Current behaviour: the code embeds FigSumo's full calculator keypad, which includes the four basic operations plus scientific functions. A simpler four-function version is planned, and the embed code on this page will switch to it when it's ready.
What visitors can do
Add, subtract, multiply and divide, with brackets
Use percentages and change signs (±)
Correct mistakes with Back, or clear with AC
Reuse the last answer (Ans) and store a running total in memory (M+, M−, MR)
Type on a keyboard when the calculator is focused: digits, + − * /, Enter or = to calculate, Backspace and Escape
Order of operations
The calculator follows standard precedence: brackets first, then powers, then multiplication and division, then addition and subtraction. Some cheap pocket calculators work left to right instead, which causes confusion.

Design and accessibility tips
Choose a width that fits your column; 320–400 px works in a sidebar.
Keep the title attribute so screen readers can announce the frame.
Leave a little space above and below; the frame has a fixed height of 520 px.
loading="lazy" delays loading until the widget is near the screen, which helps page speed.
Notes for US, Canada and UK site owners
Decimal style: the widget uses a full stop as the decimal point. That suits US, English-Canadian and UK audiences. French-Canadian visitors who write 2,5 should type 2.5.
Currency: the calculator has no currency symbol, so the same widget works for dollars and pounds. Prices that include tax (UK VAT) or exclude it (US sales tax, Canadian GST/HST) are entered the same way.
Accessibility law: public-sector sites in the US (Section 508), Canada (the Accessible Canada Act and provincial laws such as Ontario's AODA) and the UK (the Public Sector Bodies Accessibility Regulations 2018) have accessibility duties. Keep the iframe's title attribute and check that the widget works for your users.
Testing before you publish
1. Paste the code on a draft or preview page first.
2. Check the frame on a phone: if the keypad is cut off, reduce the width or allow the column to scroll.
3. Try a few sums with the keyboard and with taps, including 2+3*4, which should give 14.
4. Make sure your site's content security policy allows frames from figsumo.com.
