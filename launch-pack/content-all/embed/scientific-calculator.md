H1: Free Scientific Calculator Widget
Schools, tutoring services, engineering blogs and science sites often need a calculator that does more than add and subtract. This page lets you test FigSumo's scientific calculator and copy an embed code to place the same calculator on your own pages, free.
How to use the embed generator
1. Sample expression: type an expression, such as sin(30)+sqrt(16), to check the calculator's result. The preview evaluates in degree mode.
2. Embed width (px): 280 to 960 (default 480).
3. Copy the embed code from the results:
<iframe src="https://figsumo.com/scientific-calculator" width="480" height="560" style="max-width:480px;border:0;border-radius:8px" loading="lazy" title="FigSumo calculator"></iframe>
